\#EKF 姿态估计笔记

基于 ICM20948 的飞控姿态解算，包含四元数与陀螺仪零偏的同时估计。

核心逻辑：陀螺仪负责预测，加速度计负责修正。



一、核心作用与状态量定义

1.1 核心作用

陀螺仪：负责预测



加速度计：负责修正



同时估计：四元数姿态（q0, q1, q2, q3） + 陀螺仪零偏（bgx, bgy）



当前状态：6维，未加入 bgz



1.2 状态向量

x = \[q0, q1, q2, q3, bgx, bgy]



二、预测阶段 (Predict)

2.1 零偏修正

gx\_corrected = gx - bgx

gy\_corrected = gy - bgy



2.2 状态预测

上一时刻姿态 → 陀螺仪角速度 → 四元数传播 → 得到 x\_pred



2.3 协方差预测

公式：P\_pred = F \* P \* F^T + Q



F（6x6）：状态转移矩阵。描述上一时刻状态如何影响下一时刻，即状态变化模型的线性化结果。



P（6x6）：当前状态的不确定性。包含各状态自身的方差，以及不同状态间的相关性。



Q（6x6）：过程噪声。表示运动模型并非完全准确，预测过程中产生的额外不确定性。



三、更新阶段 (Update)

3.1 加速度计观测

观测向量：z = \[ax, ay, az]（共3个测量量）



H（3x6）：观测矩阵。描述“6个状态”如何映射到“3个传感器观测”，即 \[q0..q3, bgx, bgy] -> \[ax, ay, az]。



R（3x3）：测量噪声。R大 → 不太相信加速度计；R小 → 更相信加速度计。



3.2 卡尔曼增益

公式：K = P \* H^T \* (H \* P \* H^T + R)^-1

本质：预测结果与传感器测量之间的融合权重。



3.3 新息 (Innovation)

公式：innovation = z - h(x\_pred)

理解：加速度计实际测量值 - 根据预测姿态计算的理论加速度 = 预测误差



3.4 状态更新

公式：x\_new = x\_pred + K \* innovation

理解：预测值 + 卡尔曼增益 × 预测误差 = 修正后的状态



3.5 协方差更新

公式：P\_new = (I - K \* H) \* P\_pred

理解：经过传感器修正之后，重新计算当前状态的不确定性。



四、完整算法流程 (数据流)

ICM20948 -> 读取陀螺仪+加速度计 -> 陀螺仪减零偏 -> 四元数预测 -> 计算 F -> P\_pred = FPF^T + Q -> 加速度计观测 -> 计算 H -> 计算 K -> 计算 innovation -> x = x\_pred + K×innovation -> 更新 P -> 得到最终姿态 -> Roll / Pitch / Yaw



五、在飞控工程中的位置

ICM20948 -> Bsp\_imu -> attitude\_task -> Attitude\_Update() -> EKF -> Attitude\_GetEuler() -> Roll/Pitch/Yaw -> control\_task



六、核心概念速查表

四元数：表示姿态



状态 x：我现在认为自己是什么状态



F：状态怎么变化



P：我对这个状态有多确定



Q：我对运动模型有多不确定



H：状态怎么映射到传感器



R：我有多相信传感器



K：预测和测量怎么融合



Innovation：预测和实际差多少



状态更新：根据误差修正状态



七、关键公式速查

预测：

x\_pred = f(x, u)

P\_pred = F \* P \* F^T + Q



更新：

K = P\_pred \* H^T \* (H \* P\_pred \* H^T + R)^-1

x\_new = x\_pred + K \* (z - h(x\_pred))

P\_new = (I - K \* H) \* P\_pred

\# 基础油门笔记



\## 1. 基础油门的通用表达



基础油门是为了产生目标推力，在当前电池电压下所需要的电机基准油门。



通用表达：



T\_base = f(F, V)



其中：



T\_base：基础油门

F：目标推力

V：当前电池电压

f(F,V)：通过实验得到的推力-电压-油门映射关系



\---



\## 2. 常用二次拟合模型



T\_base = a0 + a1\*F + a2\*V + a3\*F^2 + a4\*F\*V + a5\*V^2



通过实验采集：



推力 F

电压 V

油门 T



再使用最小二乘法拟合出 a0\~a5。



\---



\## 3. 当前 无人机 实际拟合公式



T = 1537.96029618

&#x20; + 8.70113970\*F

&#x20; - 225.50577912\*V

&#x20; - 0.00880428\*F^2

&#x20; - 0.23781058\*F\*V

&#x20; + 9.01035198\*V^2



当前实验范围：



推力：0 \~ 319 g

电压：10 \~ 12.5 V

油门：48 \~ 1148



\---



\## 4. 基础油门与 PID 的关系



基础油门负责提供当前目标推力所需要的“基准油门”。



PID 负责根据姿态和角速度误差，对各个电机进行修正。



最终：



电机最终油门 = 基础油门 + PID修正量



即：



T\_motor = T\_base + ΔT



\---



\## 5. C语言中的基础油门



static uint16\_t base\_throttle = 48;



这里的 48 不是说“基础油门永远等于48”。



48只是变量上电后的初始安全值。



真正的基础油门来自拟合公式：



base\_throttle = Weight\_To\_Throttle(target\_thrust, g\_robotVOL);



也就是根据目标推力和当前电池电压，计算真正的基础油门。



\---



\## 6. 初始化和赋值



初始化：



static uint16\_t base\_throttle = 48;



表示变量建立时先给它一个初始值48。



运行过程中的：



base\_throttle = Weight\_To\_Throttle(target\_thrust, g\_robotVOL);



属于再次赋值。



函数中的 return 会把计算结果交给调用者：



return throttle;



调用者接收：



base\_throttle = Weight\_To\_Throttle(target\_thrust, g\_robotVOL);
