# Quadcopter-FC

**自主四旋翼飞控 · STM32F405 HAL 库 + FreeRTOS**

互补滤波姿态解算 · 串级 PID 姿态控制 · DShot300 数字电调 · 激光定高 · MATLAB PID/LQR 对比仿真

---

## 项目简介

本项目是一套个人从零实现的**自主四旋翼飞行控制系统**，目标不是直接使用现成商业固件，而是把四轴的关键技术链路逐层打通：IMU 读取、姿态解算、串级 PID、四旋翼混控、DShot300 输出、安全状态机与激光定高。

固件核心代码采用 **STM32Cube HAL + FreeRTOS** 的软件生态，算法模块与板级代码分层设计：仓库中的姿态估计、控制、混控、安全、高度估计等模块可在 CubeMX 生成的工程中按任务调用；MATLAB 一侧使用同一套非线性模型分别完成串级 PID 与 LQR 的姿态控制实验，为实机控制方案提供可复现的仿真依据。

---

## 功能特性

| 功能 | 说明 |
| ---- | ---- |
| IMU 驱动 | ICM-20948 芯片校验、量程配置、加速度/陀螺仪 SI 单位换算 |
| 姿态解算 | 陀螺积分 + 加速度修正的互补滤波，输出 roll/pitch/yaw |
| 串级 PID | 角度外环 → 角速度内环，内环积分带限幅与抗饱和 |
| DShot300 | 16 位 DShot 帧编码、CRC 校验、归一化油门映射 |
| Quad-X 混控 | 总拉力与三轴力矩反解到四路电机指令，输出自动限幅 |
| 安全状态机 | 解锁/锁定/缓降/故障保护，状态迁移可记录原因 |
| 激光定高 | 向上激光测距滤波，估计高度与垂直速度 |
| MATLAB 仿真 | 12 状态非线性模型，PID 与 LQR 同条件对比 |

## 控制架构

```
                    +------------------------------------------+
  遥控/任务指令       |           FreeRTOS 任务调度               |
      |              |                                          |
      v              |  +----------------+    IMU / 激光 / 定点  |
 [模式与安全状态机]   |  |   sensor_task   |<------ 传感器采集    |
      |              |  +----------------+                      |
      v              |        | 最新测量                         |
 目标姿态 / 目标高度  |        v                                 |
      |              |  +----------------+                      |
      v              |  | estimator_task  |  姿态 / 高度估计      |
 [外环位置/高度PID]   |  +----------------+                      |
      |              |        |                                |
      v              |  +----------------+  500 Hz              |
 [姿态角度环 P] ------|->|  control_task  | 串级 PID            |
      |              |  +----------------+                      |
      v              |        | 力矩指令                         |
 [角速度内环 PID] ----|->  mixer（Quad-X）                       |
                    |        |                                  |
                    |        v                                  |
                    |  +----------------+    DShot300           |
                    |  |   motor_task    |---> 电调 / 电机       |
                    |  +----------------+                      |
                    +------------------------------------------+
```

### FreeRTOS 任务划分

| 任务 | 周期 | 优先级 | 职责 |
| ---- | ---- | ---- | ---- |
| `sensor_task` | 1 kHz 事件驱动 | 高 | IMU、激光、定点传感器采集 |
| `estimator_task` | 500 Hz | 高 | 姿态与高度估计 |
| `control_task` | 500 Hz | 高 | 串级 PID / LQR 姿态控制 |
| `motor_task` | 随控制任务触发 | 高 | DShot300 帧输出 |
| `safety_task` | 100 Hz | 中 | 解锁/锁定与故障保护状态机 |
| `rc_task` | 50 Hz | 中 | 遥控指令解析 |
| `telemetry_task` | 50 Hz | 低 | 串口/上位机数据输出 |

> 实时任务使用固定周期与绝对延时；只有安全状态机能决定电机输出是否到达 DShot 驱动，模块只负责计算，不直接解锁电机。

## 核心代码分层

| 层 | 内容 | 说明 |
| ---- | ---- | ---- |
| `Algorithm/` | 姿态估计、串级 PID、混控、安全状态机、高度估计 | 自研算法模块，不直接依赖 HAL |
| `Hardware/` | ICM-20948、DShot300 | 传感器与数字输出协议封装 |
| `System/` | 公共类型、状态枚举 | 各模块共享的接口类型 |
| `Matlab/` | 非线性模型、PID/LQR 仿真 | 用同一模型对比两种控制器 |

算法模块通过**函数接口和回调接口**接入工程层：I2C 读写由 CubeMX 工程提供回调，任务按周期调用估算与控制模块。这样板级引脚、传感器硬件或 RTOS 调度方式变化时，核心算法不需要重写。

## MATLAB 仿真

仿真使用基础 MATLAB，无需额外工具箱（LQR 工具箱缺失时自动使用解析解）。

```matlab
cd Matlab
run_all_simulations
```

执行后得到：

- 串级 PID 姿态阶跃跟踪曲线与控制力矩；
- LQR 姿态控制器在同一条指令、同一扰动下的响应曲线；
- 用于对比和记录的两组实验数据。

动力学参数放在 `quadcopter_parameters.m`，装机后按实测台架数据更新并保留 git 历史。

| 编程语言 | C |

## 编译与烧录

1. 使用 STM32CubeMX 按 `docs/06_工程集成.md` 创建 STM32F405RGTx 工程；
2. 将 `Algorithm/`、`Hardware/`、`System/` 加入 Keil 的 Source Group 与 Include Path；
3. 在 FreeRTOS 任务中接入估算与控制模块，任务周期见上表；
4. 使用 Keil MDK 编译，通过 ST-Link / SWD 下载到板子。

实机联调必须严格遵守 `docs/05_安全与调参.md`：拆桨优先、装桨前完成验收门槛、故障保护必须实测、所有参数改动都要留记录。
