# 03 算法设计

## 1. 坐标系

- 机体坐标系 $b$：x 前，y 右，z 下（航模惯例）。
- 地面坐标系 $n$：NED。
- 欧拉角顺序：先偏航 $\psi$、再俯仰 $\theta$、后横滚 $\phi$（Z-Y-X），姿态角范围限制在无奇异的工作区。

旋转矩阵 $R_b^n$ 由 $\phi,\theta,\psi$ 构造，用于把机体推力转换到地面系。

## 2. 姿态解算：互补滤波

陀螺仪短时准确但会积分漂移，加速度计无漂移但动态下有振动噪声。互补滤波把两者按频率融合：

$$\dot{q} = \frac{1}{2} q \otimes \begin{bmatrix}0\\ \omega\end{bmatrix} + K_p \, e_{acc}$$

工程实现上的做法：

1. 用陀螺角速度对四元数做一阶积分；
2. 用加速度构造重力方向误差 $e_{acc} = a_{norm} \times g_{ref}$；
3. 把误差比例项反馈到角速度/四元数更新，构成“陀螺积分 + 加速度修正”；
4. 先做零偏校准，再做解算。

> 仓库中给出的 `fc_attitude_estimator` 即这一结构的实现；传感器读取与时间基准由工程层提供，算法模块保持独立。

## 3. 串级 PID 姿态控制

### 3.1 结构

角度外环输出期望角速度，角速度内环输出力矩指令：

$$\omega_{ref} = K_{p,\theta}\, e_\theta$$

$$\tau = K_{p,\omega}\, e_\omega + K_{i,\omega} \int e_\omega dt + K_{d,\omega} \frac{d e_\omega}{dt}$$

### 3.2 实现要点

- 内环积分带抗饱和，只在可执行范围内累计；
- 角速度限幅，防止大姿态误差时积分饱和；
- 偏航环单独处理，roll/pitch 用小角度误差。

## 4. LQR 姿态控制

在悬停点线性化：

$$\dot{x} = A x + B u,\quad x = [\phi,\theta,\psi,\ p,q,r]^T,\quad u = [\tau_x,\tau_y,\tau_z]^T$$

小角度下有 $A = \begin{bmatrix}0 & I_3 \\ 0 & 0\end{bmatrix}$，$B = \begin{bmatrix}0 \\ I^{-1}\end{bmatrix}$。代价函数：

$$J = \int_0^\infty (x^T Q x + u^T R u)\,dt$$

用 MATLAB 的 `lqr` 求解反馈增益 $K$，控制律 $u = -K x$。同一非线性模型上对比 PID 与 LQR，输出结果用于决定实机采用哪条路线。

## 5. 电机混控与 DShot300

X 型四旋翼四个电机绕机体 z 方向产生推力，roll/pitch/yaw 由差速产生。归一化电机指令由总拉力与三轴力矩反解：

$$u = M^{-1} [T, \tau_x, \tau_y, \tau_z]^T$$

- 输出范围映射到 DShot300 的 0~1000 油门码；
- 必须预先核对电机编号、转向与安装方向，任何错一项都可能导致解锁即翻；
- DShot 数字电调由 MCU 发送帧，无 PWM 脉宽概念。

## 6. 高度与定点

- 高度：向上激光输出距离，做滑动平均/一阶滤波后进入高度环；低空滤波带宽高，高空噪声会增大。
- 定点方案 A（二维雷达）：解析协议帧得到二维位置/速度观测量，做旋转补偿与坐标变换；
- 定点方案 B（光流）：输出体轴位移/速度，需要与 IMU 角速度做旋转补偿；
- 两条路线都在位置环外再套速度环，内部接姿态环，形成“位置→速度→姿态→角速度”四层控制。

## 7. MATLAB 模型

模型状态：$[p_n,\ p_e,\ p_d,\ v_n,\ v_e,\ v_d,\ \phi,\theta,\psi,\ p,q,r]$。输入为总拉力 $T$ 与机体三轴力矩。仿真脚本同时提供模型参数文件，方便以后按实测数据标定。
