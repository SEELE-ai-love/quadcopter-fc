# 05 安全与调参

## 1. 强制安全底线

以下规则不可妥协：

1. 任何带桨测试前必须拆桨或固定机架；
2. 拆桨/装桨前完成对应验收门槛；
3. 不熟悉解锁逻辑前不接电池；
4. 每个调参步骤都必须记录，禁止“调到合适为止”；
5. 突发情况优先遵守“解锁即油门可控、异常即锁定”的状态机。

## 2. 解锁与安全状态机

| 状态 | 条件 | 动作 |
| --- | --- | --- |
| DISARMED | 默认 | 电机锁定 |
| ARMED | 满足解锁条件且遥控在最低油门 | 允许电机输出，限幅 |
| LANDING | 定高/定点模式检测到故障 | 缓降 |
| FAILSAFE | 失联/低电压/传感器异常 | 自动落地并锁定 |
| EMERGENCY | 姿态异常/IMU 失效 | 立即锁定 |

状态迁移规则：

- 只有 DISARMED → ARMED 需要显式解锁；
- 任何故障都向更安全的状态迁移，不允许自动重新解锁；
- 状态迁移要记录时间戳与原因。

## 3. 故障保护矩阵

| 故障 | 检测方式 | 保护动作 |
| --- | --- | --- |
| 遥控失联 | 接收机超时 | FAILSAFE → LANDING |
| 低电压 | 电压采样低于阈值 | LANDING 缓降 |
| IMU 数据无效 | WHO_AM_I/数据率/跳变检查 | 禁止解锁或 EMERGENCY |
| 激光异常 | 数据率/范围超限 | 退出定高，切手动 |
| 姿态发散 | 角速度/欧拉角超限 | EMERGENCY 锁定 |
| 电机输出异常 | 输出一致性检查 | 禁止解锁 |

## 4. 调参流程

推荐顺序：内环（角速度）→ 外环（角度）→ 高度环 → 位置环。

单次实验记录表：

| 项目 | 内容 |
| --- | --- |
| 日期/环境 | 室内/室外、风况、电量 |
| 固件版本 | git commit / 编译时间 |
| 参数改动 | 改动项、旧值、新值 |
| 期望响应 | 阶跃/悬停/扰动 |
| 实测数据 | 曲线文件或日志编号 |
| 结论 | 是否收敛、下一步 |

每次调参只改一个参数；改完必须复测上一组数据作为对照。

## 5. 装桨前验收门槛

只有全部满足才允许装桨：

- [ ] S3 电机编号/转向全部正确；
- [ ] 解锁逻辑经过拆桨验证；
- [ ] 遥控最低油门确认安全；
- [ ] 故障保护至少完成一项实测（如低电压/失联）；
- [ ] 应急预案与场地准备完成；
- [ ] 调参记录从 S4 起连续完整。
