# 04 开发路线与验收

> 每个 Stage 的验收都必须是**可复现、可记录**的。实机通电前先拆桨。装桨试飞有单独的前置门槛（见 `05_安全与调参.md`）。

## S1：板子识别与串口验证

目标：确认板子能烧录、能复位、能稳定打印。

CubeMX 关键配置：

1. 芯片 STM32F405RGTx；
2. RCC：HSE Crystal，SYSCLK 168 MHz；
3. SYS Debug: Serial Wire；
4. 串口：USART1 PA9(TX)/PA10(RX)，115200，8N1；
5. Keil 中重定向 `printf` 到串口。

验收：

- 上电串口稳定打印版本、复位计数、任务心跳；
- 复位前后输出正确；
- 串口不丢帧（1000 行测试）。

## S2：IMU 读取与姿态解算

目标：把 ICM-20948 原始数据变成 roll/pitch/yaw。

步骤：

1. I2C1 初始化，读 WHO_AM_I 验证在线；
2. 陀螺/加速度量程配置；
3. 静止时统计零偏与噪声；
4. 串口打印原始 acc/gyro；
5. 加入四元数 + 卡尔曼滤波，打印 roll/pitch/yaw；
6. 用手转动板子，与 3D 姿态模型/地面站对比。

> 此阶段禁止任何电机输出。

验收：

- 静止时欧拉角稳定，噪声有界；
- 慢转 90° 后读数误差小于允许阈值（如 2°）；
- 连续运行 10 分钟无异常漂移。

## S3：DShot300 与电机方向

目标：验证四路电机输出、编号与转向。

强制：全程拆桨、固定机架、油门限幅。

步骤：

1. TIM8 PWM 初始化，确定 PC6-PC9 的通道映射；
2. 发送最低油门帧确认电调上电识别；
3. 逐路给固定油门，核对电机编号与旋转方向；
4. 核对混控符号：roll 指令只应引起对应轴转动。

验收：

- 每路电机只响应自己的通道；
- 电机转向与图纸一致；
- 波形/转速记录存档。

## S4：串级 PID 姿态闭环

前置：S2、S3 全部通过。

流程：

1. 在 MATLAB 中用同一组参数跑仿真，记录预期响应；
2. 拆桨状态检查姿态环输出符号与限幅；
3. 室内小空间试飞或系留测试，先手动自稳模式；
4. 逐轴调角速度环 P，再调角度环 P，再调积分。

验收：

- 姿态阶跃无发散、无持续振荡；
- 每个参数改动都有日志记录；
- 记录油门/姿态/角速度曲线。

## S5：状态机与定高

内容：

1. 解锁/锁定条件、摇杆手势或按键逻辑；
2. 低电压、失联、传感器异常进入安全状态；
3. 接入向上激光，滤波后打印高度；
4. 高度环闭环，先在低高度小油门验证。

验收：

- 人为触发故障后飞机按状态机动作（锁定/缓降）；
- 定高高度误差满足指标；
- 保护触发时间与日志完整。

## S6：定点与算法对比

内容：

1. 光流或二维雷达协议解析与坐标补偿；
2. 位置/速度环调试；
3. PID 与 LQR 在 MATLAB 的对比实验收尾；
4. 选择实机路线并归档数据。

验收：

- 定点悬停漂移满足验收指标；
- 控制算法选择有仿真+实测数据支撑；
- 项目文档、许可证、引用边界全部清理后可发布。
