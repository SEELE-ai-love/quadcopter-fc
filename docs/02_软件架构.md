# 02 软件架构

## 1. 架构原则

- 算法代码与应用逻辑分离，硬件驱动只通过接口被调用；
- 每个实时任务有固定周期，数据通过队列/互斥量共享；
- 安全逻辑不依赖调试串口或地面站；
- 关键参数集中管理，便于归档和复现。

## 2. FreeRTOS 任务划分

| 任务 | 周期 | 职责 |
| --- | --- | --- |
| sensor_task | 1 kHz 事件驱动 | 采集 IMU/激光/定点传感器 |
| estimator_task | 500 Hz | 姿态解算（四元数 + 卡尔曼滤波） |
| control_task | 500 Hz | 串级 PID / LQR 控制 |
| motor_task | 由控制任务触发 | DShot300 输出 |
| safety_task | 100 Hz | 解锁/锁定、故障保护状态机 |
| telemetry_task | 50 Hz | 串口/蓝牙打印与上位机 |
| rc_task | 50 Hz | 遥控指令解析 |

## 3. 数据流

```text
IMU/激光/定点传感器
        |
   sensor_task（采集原始帧）
        |
safety_task ──► estimator_task（姿态/高度/位置估计）
                     |
                control_task（外环→内环）
                     |
                mixer（四旋翼混控）
                     |
                DShot300 → 电调/电机
```

## 4. 固件模块映射

| 模块 | 位置 | 说明 |
| --- | --- | --- |
| 类型/参数 | `System/` | 公共类型、飞行状态枚举 |
| 姿态估计 | `Algorithm/fc_attitude_estimator` | 四元数状态卡尔曼滤波 |
| 通用 PID | `Algorithm/fc_pid` | 积分限幅与抗饱和 |
| 串级 PID 控制 | `Algorithm/fc_controller` | 角度环→角速度环 |
| 四旋翼混控 | `Algorithm/fc_mixer` | Quad-X 分配与归一化 |
| 安全状态机 | `Algorithm/fc_safety` | 解锁/锁定/故障保护 |
| 高度估计 | `Algorithm/fc_height` | 激光滤波与垂直速度估计 |
| IMU 驱动 | `Hardware/fc_icm20948` | 寄存器校验、量程配置与 SI 换算 |
| DShot300 | `Hardware/fc_dshot300` | 帧编码、CRC 与油门映射 |

## 5. 实时性要求

- 控制周期必须稳定，中断/高优先级任务里不做浮点打印；
- 传感器数据要带时间戳，估算与控制使用同一份最新数据；
- 任何“假数据”路径（例如桌面仿真）要有明确开关，禁止在实机误开。
