# 02 软件架构

## 1. 架构原则

- 算法代码与应用逻辑分离，硬件驱动只通过接口被调用；
- 每个实时任务有固定周期，数据通过队列/互斥量共享；
- 安全逻辑不依赖调试串口或地面站；
- 关键参数集中管理，便于归档和复现。

## 2. FreeRTOS 任务划分

| 任务 | 周期 | 职责 |
| --- | --- | --- |
| sensor_task | 1 kHz 事件驱动 | 采集 IMU/激光/定点传感器 |
| estimator_task | 500 Hz | 姿态解算（互补滤波） |
| control_task | 500 Hz | 串级 PID / LQR 控制 |
| motor_task | 由控制任务触发 | DShot300 输出 |
| safety_task | 100 Hz | 解锁/锁定、故障保护状态机 |
| telemetry_task | 50 Hz | 串口/蓝牙打印与上位机 |
| rc_task | 50 Hz | 遥控指令解析 |

## 3. 数据流

```text
IMU/激光/定点传感器
        |
   sensor_task（采集原始帧）
        |
safety_task ──► estimator_task（姿态/高度/位置估计）
                     |
                control_task（外环→内环）
                     |
                mixer（四旋翼混控）
                     |
                DShot300 → 电调/电机
```

## 4. 固件模块映射

| 模块 | 文件 | 说明 |
| --- | --- | --- |
| 类型/参数 | `app/include/fc_types.h` | 公共类型、状态枚举 |
| PID | `app/src/fc_pid.c/.h` | 通用 PID（含抗饱和） |
| 混控 | `app/src/fc_mixer.c/.h` | X 型混控与 DShot 归一化 |
| 姿态估计 | `app/src/fc_attitude_estimator.c/.h` | 互补滤波 |
| 安全状态机 | `app/src/fc_safety.c/.h` | 解锁/锁定/故障保护 |
| 高度估计 | `app/src/fc_height.c/.h` | 激光滤波与融合 |
| 控制 | `app/src/fc_controller.c/.h` | 串级 PID / LQR 调度 |

## 5. 实时性要求

- 控制周期必须稳定，中断/高优先级任务里不做浮点打印；
- 传感器数据要带时间戳，估算与控制使用同一份最新数据；
- 任何“假数据”路径（例如桌面仿真）要有明确开关，禁止在实机误开。
