# 01 硬件平台

> 本文档只描述项目当前使用的验证硬件与资源分配，具体引脚以实物丝印和原理图为准。进入自制 PCB 阶段后，本章按自己的板子单独补充。

## 1. 主控

| 项目 | 值 |
| --- | --- |
| MCU | STM32F405RGT6 |
| 封装 | LQFP64 |
| 主频 | 168 MHz |
| 开发方式 | STM32CubeMX + HAL + FreeRTOS (CMSIS-RTOS v2) |
| 调试口 | SWD |

## 2. 传感器与外设

| 外设 | 型号/接口 | 说明 |
| --- | --- | --- |
| IMU | ICM-20948，I2C1 PB6/PB7 | 加速度 + 陀螺仪 |
| 高度 | 向上激光测距，UART5 PC12/PD2 | 定高主传感器 |
| 二维雷达 | UART2 PA2/PA3 | 定点可选方案 A |
| 光流 | UART3 PB10/PB11 | 定点可选方案 B |
| 蓝牙/APP | UART4 PC10/PC11 | 地面站/调试 |
| PS2 接收机 | USB Host PA11/PA12 | 遥控输入 |

## 3. 电机输出

| 电机 | 引脚 | 定时器 |
| --- | --- | --- |
| M1 | PC6 | TIM8_CH1 |
| M2 | PC7 | TIM8_CH2 |
| M3 | PC8 | TIM8_CH3 |
| M4 | PC9 | TIM8_CH4 |

协议：**DShot300**。

> 注：DShot300 的引脚组合与具体通道配置要以自己生成的 CubeMX 工程为准。

## 4. 机械与动力（首版仿真参数，装机后按实测标定）

| 参数 | 说明 |
| --- | --- |
| 机架 | X 型四旋翼 |
| 电机-电机对角线 | 以实测为准 |
| 推力系数 | 由 MATLAB 模型参数文件标定 |
| 阻力系数 | 由 MATLAB 模型参数文件标定 |
| 电池 | 以实际配置为准 |

不沿用任何旧机型的推力/惯量数值，装机后按 `05_安全与调参.md` 的流程重新标定。
