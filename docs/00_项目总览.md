# 00 项目总览

## 1. 项目定位

本项目是一个**自主四旋翼飞行控制系统**，从零搭建自己的飞控软件，并在 MATLAB 中建立飞机模型来验证 PID 与 LQR 两种控制方案。项目不复制现有商业固件，而是把关键链路（传感器、姿态估计、控制、输出、状态机）逐个模块自己写出来。

## 2. 目标

1. 能安全解锁/锁定，姿态可控地悬停；
2. 具有可复现的调参流程与飞行记录；
3. 用 MATLAB 模型先验证控制算法，再移植到固件；
4. 完整记录开源过程中用到的第三方资料边界，避免许可证纠纷。

## 3. 范围边界

### 第一版做

- ICM-20948 读取与姿态解算（四元数 + 卡尔曼滤波）；
- DShot300 电机输出与四旋翼混控；
- 串级 PID 姿态控制；
- 安全状态机、拆桨调试与故障保护；
- 激光定高；
- PID 与 LQR 的 MATLAB 对比仿真。

### 第一版不做

- 不做 PCB 自制与焊接（硬件后续单独迭代）；
- 不做复杂自主航线规划；
- 不做视觉识别/目标跟踪；
- 不做 GPS/磁力计组合导航（除非后续增加硬件）。

## 4. 里程碑总览

| 里程碑 | 内容 | 完成判据 |
| --- | --- | --- |
| M1 | 板子识别与串口验证 | 串口稳定打印系统信息 |
| M2 | IMU + 姿态解算 | 手转板子，上位机/串口实时显示 roll/pitch/yaw |
| M3 | DShot300 + 混控方向 | 拆桨状态完成四路电机转速指令验证 |
| M4 | 串级 PID 姿态闭环 | 姿态模式下可稳定悬停，无振荡/发散 |
| M5 | 状态机 + 定高 | 定高模式保持高度，触发保护能自动落地/锁定 |
| M6 | 定点与算法对比 | 定点误差满足验收指标，PID 与 LQR 实验数据完成归档 |
